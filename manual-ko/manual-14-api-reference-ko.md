# 14장 - API 참조

공개 함수 하나하나의 설명은 영어판 [14장 API 참조](../manual/manual-14-api-reference.md)에 있다. 그 장은 헤더
(`include/gates/*.h`)의 주석에서 `tests/api_reference.sh` 가 만들어 내므로, 헤더와 늘 같은 내용이다. 함수는 헤더별로,
헤더 안의 절(section) 순서대로 실려 있고, 선언은 한 줄로 보인다. `[[nodiscard]]` 가 붙은 함수는 결과를 반드시 살펴야 한다.

한국어 번역은 아직 없다. 다른 장에서 쓰임새를 익히고, 정확한 조건(무엇을 거절하는지, 무엇이 조용히 바뀌는지)은 영어판
참조나 헤더의 주석에서 찾으면 된다. `make manual-check` 는 주석 없는 공개 함수가 있거나 참조 장이 헤더와 어긋나면 실패한다.
