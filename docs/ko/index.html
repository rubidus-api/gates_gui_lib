gates 매뉴얼

도구형 Windows 프로그램을 위한 작은 C23 retained GUI 라이브러리

판 0.15.0 · MIT 라이선스

github.com/rubidus-api/gates_gui_libPDF

gates 로 도구형 Windows 프로그램을 만드는 법을 담는다. 노드 트리, 컨트롤과 배치, 폼, 명령, 데이터 뷰, 글, 작업자, 테마, 접근성, 앱 틀, 그리고 함수 하나하나의 API 참조(영어).

영어판이 원본이고 이 판은 그 번역이다. 둘이 어긋나면 영어판을 따른다.
